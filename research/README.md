# Research archive

This directory preserves exploratory work that motivated the supported
`block_gnn` package. It is intentionally excluded from package discovery and CI
correctness guarantees.

- `legacy_notebooks/` contains cleaned historical sparse-operator notebooks.
- `legacy_src/` contains the original 2024 Python prototypes.
- `gnn_mnist/` preserves a separate, unfinished GNN classification direction.

The archive documents the path from dense adjacency experiments to the current
inference compiler. It should not be imported by applications.
